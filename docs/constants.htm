Welcome Concepts Getting Started Function Reference Constants

Constants

Window Dimensions

$WIN_WIDTHDefault window width in pixels (540).
$WIN_HEIGHTDefault window height in pixels (345).

Font

$FONT_NAMEDefault font family name ("Segoe UI").
$FONT_SIZEDefault font point size (11).

Button Dimensions

$BTN_WDefault button width in pixels (130).
$BTN_HDefault button height in pixels (34).
$BTN_GAPDefault horizontal gap between buttons in pixels (10).
$BTN_YDefault Y position of the button row ($WIN_HEIGHT - 48).

Layout Metrics

$FOOTER_SEP_YDefault Y position of the footer separator line ($WIN_HEIGHT - 58).
$HEADER_HDefault height of the header band in pixels (70).
$CONTENT_TOPDefault Y position where page content begins ($HEADER_H + 10).
$CONTENT_WDefault width available to page content ($WIN_WIDTH - 40).

Default Button Captions

$BTN_CAPTION_NEXTDefault Next button caption ("Next >").
$BTN_CAPTION_BACKDefault Back button caption ("< Back").
$BTN_CAPTION_CANCELDefault Cancel button caption ("Cancel").
$BTN_CAPTION_FINISHDefault Next-button caption on the finish page ("Finish").
$BTN_CAPTION_APPLYDefault Next-button caption on a ready/proceed page ("Install").

Button Map Keys

$BTN_CANCELMap key for the Cancel button ID ("idBtnCancel").
$BTN_BACKMap key for the Back button ID ("idBtnBack").
$BTN_NEXTMap key for the Next button ID ("idBtnNext").

Page Navigation Direction (Enum)

$ePageBackMove to the previous page (-1).
$ePageStayStay on the current page (0).
$ePageNextMove to the next page (1).

Page Position (Enum)

$eInvalidPageThe page index does not exist (-1).
$eSinglePageThe wizard has exactly one page.
$eFirstPageThe first page of a multi-page wizard.
$eMidPageA page between the first and last.
$eLastPageThe last page of a multi-page wizard.

Page Type / Status (Enum)

$eClosePageThe wizard should close on the next navigation.
$eNormalPageAn ordinary page; Next reads its normal caption.
$eProceedPageNext switches to the configured Apply/Install caption (used by the ready page).
$eProcessingPageCancel, Back and Next are all disabled (used by the progress page).
$eFinishPageNext switches to Finish and Cancel/Back are disabled.

Page Event Aliases (Enum)

$eOnClosePageAlias of $eClosePage, used as an installer event identifier.
$eOnDefaultAlias of $eNormalPage.
$eOnReadyToProceedAlias of $eProceedPage.
$eOnProcessingAlias of $eProcessingPage.
$eOnFinishAlias of $eFinishPage.

Event Constants

$EVENT_CLOSE_PAGEInstaller event alias of $eOnClosePage, used with _SetInstallerEvent()/_GetInstallerEvent().
$EVENT_DEFAULTInstaller event alias of $eOnDefault.
$EVENT_READY_TO_PROCEEDInstaller event alias of $eOnReadyToProceed.
$EVENT_PROCESSINGInstaller event alias of $eOnProcessing.
$EVENT_FINISH_PROCESSInstaller event alias of $eOnFinish.

Event Name / Type Keys

$ONLOADPage map key for the OnLoad event ("OnLoad").
$AFTERLOADPage map key for the AfterLoad event ("AfterLoad").
$$ONLEAVEPage map key for the OnLeave event ("OnLeave").
$ONCLOSEPage map key for the OnClose event ("OnClose").
$ONCLICKPage map key for a button's OnClick event ("OnClick").

Wizard Control

$EXIT_WIZARD_SIGNALSignal value returned internally to exit the main wizard loop and delete the GUI (-9).
$DEFAULT_VERSIONDefault version string shown on the intro page when none is specified ("0.0.1").

Error Codes

$INST_ERR_INVALID_WIZARDThe wizard map is missing required keys (1).
$INST_ERR_INVALID_CFGThe config map is missing or has invalid values (2).
$INST_ERR_INVALID_GUIThe GUI handle is not a valid window (3).
$INST_ERR_INVALID_CTRLThe control ID or index is invalid (4).
$INST_ERR_INVALID_AIMRArray replace received invalid parameters (5).

Error Messages

$INST_ERR_MSG_WIZARDHuman-readable message for $INST_ERR_INVALID_WIZARD.
$INST_ERR_MSG_CFGHuman-readable message for $INST_ERR_INVALID_CFG.
$INST_ERR_MSG_GUIHuman-readable message for $INST_ERR_INVALID_GUI.
$INST_ERR_MSG_CTRLHuman-readable message for $INST_ERR_INVALID_CTRL.
$INST_ERR_MSG_AIMRHuman-readable message for $INST_ERR_INVALID_AIMR.
$INST_ERR_MSG_UNKNOWNFallback message used for an unrecognized error code.
