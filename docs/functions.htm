Welcome Concepts Getting Started Function Reference Constants

Function Reference

Configuration

_NewWndCfgCreates a window dimension config map with the layout metrics used to position the header, footer separator and content area.
_NewFontCfgCreates a font config map with a font name and size, used for every label and button the wizard creates.
_NewBtnDimCreates a button dimension config map with width, height, horizontal gap and Y position for the Cancel/Back/Next button row.
_NewBtnCaptionsCreates a button captions config map with the label text for each wizard button and state.
_NewBtnCfgCreates a button config map combining button dimensions and captions. Falls back to defaults for either part if an invalid map is passed.
_NewInstallerCfgCreates the single flat installer config map that is passed throughout the wizard - all layout, font and button settings are read from it. Falls back to defaults if invalid maps are provided.

Installer Events

_GetInstallerEventReturns the current installer event state.
_SetInstallerEventSets the current installer event state.

Pages

_CreatePagesCreates and returns an empty pages map to hold wizard pages.
_NewPageCreates and returns a new page map with a subheading, status and an empty controls array.
_AddPageAdds a page to the pages map and returns its 1-based index.
_GetWizardPageReturns the page map at a given index from the wizard's pages collection.

Page Controls

_SetPageCtrlRegisters a control ID under a named key in the page map and stores it in the page's controls array.
_GetPageCtrlReturns the control ID registered under a named key in the page map.

Event Handlers

_HandlerArgsCreates a CallArgArray-style args array from up to 10 values, for use with _SetEventHandler().
_SetEventHandlerCreates an event handler map holding a function reference and optional arguments.
_SetPageBtnOnClickEventRegisters an OnClick event handler for a specific button control on a page.

Wizard Buttons

_CreateButtonsCreates the three main wizard buttons (Cancel, Back, Next) on a window and returns a buttons map.

Progress Bar

_ProgressStepUpdates the progress bar and status label for a single installer step, with a short delay before and after so the change is visible.

Page Template Events

_OnLoad_ReadyPageOnLoad handler that calls a supplied function and shows its returned text in an info label.
_AfterLoad_ProgressPageAfterLoad handler that runs an install/uninstall function and advances the wizard automatically when it finishes.
_AfterLoad_FinishPageAfterLoad handler that marks the installer event so the wizard exits on the next Next/Back/Cancel.
_OnClose_FinishPageOnClose handler that opens a file if a checkbox is checked.
_OnClick_SetFolderOnClick handler that opens a folder selection dialog and updates an input with the result.

Page Templates

_AddIntroPageCreates an intro/welcome page, adds it to the wizard and returns its page index.
_AddPathPageCreates a path selection page, adds it to the wizard and returns its page index.
_AddReadyPageCreates a ready/confirm page, adds it to the wizard and returns its page index.
_AddProgressPageCreates a progress page, adds it to the wizard and returns its page index.
_AddFinishPageCreates a finish page, adds it to the wizard and returns its page index.

Header Construction

_CreateSeparatorCreates a 1-pixel horizontal separator label on a window and sets its background color.
_CreateHeaderTitleCreates the header title label on a window.
_CreateHeaderSubCreates the header subtitle label on a window, updated on each page load to show the current page's subtitle.
_CreateHeaderCreates the full header bar on a window, including the background band, title, subtitle and separator line.

Wizard

_NewWizardCreates and returns a new wizard map with a window, header, footer separator, buttons and an empty pages collection.
_InitWizardEntry point for starting the wizard - validates it is ready, then runs its event loop until the user finishes or cancels.
