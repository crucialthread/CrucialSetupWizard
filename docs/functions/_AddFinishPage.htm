_AddFinishPage

Creates a finish page, adds it to the wizard and returns its page index.

_AddFinishPage(ByRef $mWizard, Const ByRef $mCfg, $idLblProgress, $idProgressbar, $sFinishMsg, [$sDocFile = Default [, $sFinishSubHeading = ""]])

Parameters

$mWizardThe wizard map. Passed by reference; iFinishPageId is set on it.
$mCfgThe installer config map.
$idLblProgressThe progress label control ID from the progress page, reused on the finish page.
$idProgressbarThe progress bar control ID from the progress page, reused on the finish page.
$sFinishMsgThe completion message shown on the page.
$sDocFile[optional] Path to a documentation file. When provided, adds an "Open documentation" checkbox wired to _OnClose_FinishPage(). Default is Default (no checkbox).
$sFinishSubHeading[optional] The header subtitle shown when this page is active.

Return Value

SuccessThe page's 1-based index, also stored in $mWizard.iFinishPageId.
Failure0, with @error set to $INST_ERR_INVALID_WIZARD, if $mWizard is not a valid, ready wizard.

Remarks

The finish page has iStatus = $eFinishPage, which switches the Next button to the Finish caption and disables Cancel/Back. Its control IDs come from the progress page ($idLblProgress, $idProgressbar) because it reuses the same two controls, just relabeled as the completion message.

Related

_AddProgressPage, _OnClose_FinishPage

Example

Local $iProgress = _AddProgressPage($mWizard, $mCfg, _MyInstallProcess)
Local $idLblProgress = _GetPageCtrl(_GetWizardPage($mWizard, $iProgress), "LblProgress")
Local $idProgressbar = _GetPageCtrl(_GetWizardPage($mWizard, $iProgress), "Progressbar")

_AddFinishPage($mWizard, $mCfg, $idLblProgress, $idProgressbar, _
    "Setup completed successfully.", @ScriptDir & "\readme.txt", "Completing Setup")
