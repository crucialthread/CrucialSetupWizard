_AddIntroPage

Creates an intro/welcome page, adds it to the wizard and returns its page index.

_AddIntroPage(ByRef $mWizard, Const ByRef $mCfg, [$sIntroText = "" [, $sIntroSubHeading = "" [, $sIntroVersion = $DEFAULT_VERSION]]])

Parameters

$mWizardThe wizard map, as returned by _NewWizard(). Passed by reference; iIntroPageId is set on it.
$mCfgThe installer config map.
$sIntroText[optional] The welcome text shown on the page.
$sIntroSubHeading[optional] The header subtitle shown when this page is active.
$sIntroVersion[optional] The version string shown at the bottom of the page. Default is $DEFAULT_VERSION ("0.0.1"). An empty string hides the version label.

Return Value

SuccessThe page's 1-based index, also stored in $mWizard.iIntroPageId.
Failure0, with @error set to $INST_ERR_INVALID_WIZARD, if $mWizard is not a valid, ready wizard.

Remarks

The intro page is a plain $eNormalPage - it has no special button behavior and is typically the first page added.

Related

_AddPathPage, _NewWizard

Example

_AddIntroPage($mWizard, $mCfg, _
    "Welcome to the Lumen Setup Wizard." & @CRLF & @CRLF & "Click Next to continue.", _
    "Welcome", "1.2.0")
