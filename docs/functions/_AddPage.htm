Function Reference

_AddPage

Adds a page to the pages map and returns its 1-based index.

_AddPage(ByRef $mPages, ByRef $mPage)

Parameters

$mPagesThe pages map to add to, typically $mWizard.mPages. Passed by reference and modified in place.
$mPageThe page map to add, normally built with _NewPage(). Passed by reference.

Return Value

SuccessThe 1-based index the page was added at.
FailureReturns nothing (Null) when both $mPages and $mPage fail the IsMap() check.

Remarks

Always pass a real pages map built with _CreatePages() and a real page map built with _NewPage().

Related

_CreatePages, _NewPage

Example

Local $mPages = _CreatePages()
Local $mPage  = _NewPage("Welcome")
Local $iIndex = _AddPage($mPages, $mPage)
ConsoleWrite($iIndex & @CRLF)  ; 1
