_AddPathPage

Creates a path selection page, adds it to the wizard and returns its page index.

_AddPathPage(ByRef $mWizard, Const ByRef $mCfg, $sPath, $hUpdateSrcFunc, [$sPathLabel = "Install folder:" [, $sPathPageInfo = "" [, $sPathSubHeading = ""]]])

Parameters

$mWizardThe wizard map. Passed by reference; iPathPageId is set on it.
$mCfgThe installer config map.
$sPathThe initial path shown in the folder input.
$hUpdateSrcFuncCalled with the input control ID after the user picks a folder via Browse. Pass Default for no callback.
$sPathLabel[optional] The label text above the folder input. Default is "Install folder:".
$sPathPageInfo[optional] Descriptive text shown at the top of the page.
$sPathSubHeading[optional] The header subtitle shown when this page is active.

Return Value

SuccessThe page's 1-based index, also stored in $mWizard.iPathPageId.
Failure0, with @error set to $INST_ERR_INVALID_WIZARD, if $mWizard is not a valid, ready wizard.

Remarks

Adds a Browse button wired to _OnClick_SetFolder(), which opens a folder selection dialog and updates the input in place.

Related

_OnClick_SetFolder, _AddReadyPage

Example

Func _OnPathChanged($idInputPath)
    $g_sInstallPath = GUICtrlRead($idInputPath)
EndFunc

_AddPathPage($mWizard, $mCfg, @ProgramFilesDir & "\Lumen", _OnPathChanged, _
    "Install folder:", "Choose the folder where Lumen will be installed.", "Choose Install Location")
