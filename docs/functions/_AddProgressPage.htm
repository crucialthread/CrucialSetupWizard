_AddProgressPage

Creates a progress page, adds it to the wizard and returns its page index.

_AddProgressPage(ByRef $mWizard, Const ByRef $mCfg, $hFunction, [$sFailureMsg = "Process failed" [, $sProgressSubHeading = ""]])

Parameters

$mWizardThe wizard map. Passed by reference; iProgressPageId is set on it.
$mCfgThe installer config map.
$hFunctionThe install/uninstall function to run. Receives ($idLblProgress, $idProgressbar) and must return a Boolean success flag.
$sFailureMsg[optional] The error message shown if $hFunction returns False. Default is "Process failed".
$sProgressSubHeading[optional] The header subtitle shown when this page is active.

Return Value

SuccessThe page's 1-based index, also stored in $mWizard.iProgressPageId.
Failure0, with @error set to $INST_ERR_INVALID_WIZARD, if $mWizard is not a valid, ready wizard.

Remarks

The progress page has iStatus = $eProcessingPage, which disables Cancel/Back/Next while it runs. Its AfterLoad event is _AfterLoad_ProgressPage(), which runs $hFunction and clicks Next automatically once it finishes - use _ProgressStep() inside $hFunction to move the progress bar.

Related

_ProgressStep, _AfterLoad_ProgressPage, _AddFinishPage

Example

Func _MyInstallProcess($idLblProgress, $idProgressbar)
    Local $aFiles = _FileListToArray($g_sSourcePath)
    For $i = 1 To $aFiles[0]
        FileCopy($g_sSourcePath & "\" & $aFiles[$i], $g_sInstallPath & "\" & $aFiles[$i])
        _ProgressStep($idLblProgress, $idProgressbar, $i, $aFiles[0], "Copying " & $aFiles[$i])
    Next
    Return True
EndFunc

_AddProgressPage($mWizard, $mCfg, _MyInstallProcess, "Installation failed", "Installing")
