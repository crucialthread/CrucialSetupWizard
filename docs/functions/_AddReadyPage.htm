_AddReadyPage

Creates a ready/confirm page, adds it to the wizard and returns its page index.

_AddReadyPage(ByRef $mWizard, Const ByRef $mCfg, [$sReadyInfo = "" [, $sReadySubHeading = "" [, $hUpdateReadyPageFunc = Default]]])

Parameters

$mWizardThe wizard map. Passed by reference; iReadyPageId is set on it.
$mCfgThe installer config map.
$sReadyInfo[optional] Static info text, used only when $hUpdateReadyPageFunc is Default.
$sReadySubHeading[optional] The header subtitle shown when this page is active.
$hUpdateReadyPageFunc[optional] A function taking no arguments that returns dynamic info text on page load, via _OnLoad_ReadyPage(). Default is Default (use $sReadyInfo as-is).

Return Value

SuccessThe page's 1-based index, also stored in $mWizard.iReadyPageId.
Failure0, with @error set to $INST_ERR_INVALID_WIZARD, if $mWizard is not a valid, ready wizard.

Remarks

The ready page has iStatus = $eProceedPage, which switches the Next button caption to the configured Apply/Install caption.

Related

_OnLoad_ReadyPage, _AddProgressPage

Example

Func _BuildReadySummary()
    Return "Install to: " & $g_sInstallPath
EndFunc

_AddReadyPage($mWizard, $mCfg, "", "Ready to Install", _BuildReadySummary)
