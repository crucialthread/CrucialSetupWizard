_AfterLoad_FinishPage

AfterLoad handler that marks the installer event so the wizard exits on the next Next/Back/Cancel.

_AfterLoad_FinishPage()

Parameters

None.

Return Value

-No meaningful return value; calls _SetInstallerEvent($EVENT_CLOSE_PAGE).

Remarks

_AddFinishPage() registers this as the finish page's AfterLoad event automatically. Combined with the finish page's iStatus = $eFinishPage, this is what turns the Next button into Finish and closes the wizard the moment it is clicked.

It isn't limited to the finish page, though: since it takes no arguments, it's also the simplest way to make a custom page close the wizard on its next navigation - register it directly, no _HandlerArgs() needed:

Related

_AddFinishPage, _SetInstallerEvent, _SetEventHandler

Example

$mPage.AfterLoad = _SetEventHandler(_AfterLoad_FinishPage)
