_AfterLoad_ProgressPage

AfterLoad handler that runs an install/uninstall function and advances the wizard automatically when it finishes.

_AfterLoad_ProgressPage($hWin, $idLblProgress, $idProgressbar, $idBtnNext, $hFunction, $sInstallerTitle, $sFailureMsg)

Parameters

$hWinThe wizard window handle, used as the parent for the failure MsgBox.
$idLblProgressThe progress label control ID, passed through to $hFunction.
$idProgressbarThe progress bar control ID, passed through to $hFunction.
$idBtnNextThe Next button control ID, clicked programmatically once $hFunction returns.
$hFunctionThe install/uninstall function to run. Receives ($idLblProgress, $idProgressbar) and must return a Boolean success flag.
$sInstallerTitleThe wizard title, used as the failure MsgBox title.
$sFailureMsgThe message shown in the failure MsgBox if $hFunction returns False.

Return Value

-No meaningful return value. On failure, shows an error MsgBox and calls _SetInstallerEvent($EVENT_CLOSE_PAGE) so the wizard exits on the next navigation.

Remarks

The progress page registers this as its AfterLoad event automatically, passing its own progress label, progress bar and Next button control IDs along with the $hFunction, title and failure message you gave to _AddProgressPage(). Once $hFunction returns, this is what advances the wizard to the next page automatically (or shows the failure message and closes) without the user having to click anything themselves.

It isn't limited to the progress page, though: since all seven values are passed in through _HandlerArgs(), the same handler can back a custom $eProcessingPage page with its own label, progress bar and Next button - register it the same way _AddProgressPage() does internally:

Related

_AddProgressPage, _ProgressStep, _SetEventHandler

Example

Func _MyInstallProcess($idLblProgress, $idProgressbar)
    _ProgressStep($idLblProgress, $idProgressbar, 1, 1, "Done")
    Return True
EndFunc

$mPage.AfterLoad = _SetEventHandler(_AfterLoad_ProgressPage, _HandlerArgs( _
    $mWizard.hWin, $idLblProgress, $idProgressbar, $idBtnNext, _
    _MyInstallProcess, "My Setup", "The process could not complete."))
