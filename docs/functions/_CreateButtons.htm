Function Reference

_CreateButtons

Creates the three main wizard buttons (Cancel, Back, Next) on a window and returns a buttons map.

_CreateButtons($hGUI, Const ByRef $mCfg)

Parameters

$hGUIThe wizard window handle to create the buttons on.
$mCfgThe installer config map, providing button dimensions, Y position and captions.

Return Value

SuccessA map with keys idBtnCancel, idBtnBack, idBtnNext.
FailureNull, with @error set to $INST_ERR_INVALID_GUI, if $hGUI is not a valid window handle.

Remarks

The three buttons are centered horizontally as a group in the window, using $mCfg.iBtnWidth/iBtnGap to compute their total width. Called once by _NewWizard(); there is normally no need to call this directly.

Related

_NewWizard, _NewBtnDim

Example

Local $hGUI = GUICreate("My Installer", $mCfg.iWndWidth, $mCfg.iWndHeight)
Local $mButtons = _CreateButtons($hGUI, $mCfg)
If @error Then Exit MsgBox($MB_ICONERROR, "Error", "Invalid window handle")
