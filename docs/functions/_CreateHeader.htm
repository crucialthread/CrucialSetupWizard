_CreateHeader

Creates the full header bar on a window, including the background band, title, subtitle and separator line.

_CreateHeader($hGUI, Const ByRef $mCfg, [$sText = ""])

Parameters

$hGUIThe wizard window handle to create the header on.
$mCfgThe installer config map.
$sText[optional] The title text shown in the header.

Return Value

SuccessA map with keys id (the background band control), idTitle, idSubheading, idSeparator.
FailureNull, with @error set to $INST_ERR_INVALID_GUI, if $hGUI is not a valid window handle.

Remarks

Called once by _NewWizard() and stored as $mWizard.mHeader. Its idSubheading key is updated automatically on every page change.

Related

_CreateHeaderTitle, _CreateHeaderSub, _CreateSeparator, _NewWizard

Example

Local $mHeader = _CreateHeader($hGUI, $mCfg, "Lumen Setup")
GUICtrlSetData($mHeader.idSubheading, "Welcome")
