Function Reference

_CreateHeaderSub

Creates the header subtitle label on a window, updated on each page load to show the current page's subtitle.

_CreateHeaderSub($hGUI, Const ByRef $mCfg, [$sText = ""])

Parameters

$hGUIThe wizard window handle to create the label on.
$mCfgThe installer config map, providing the window width and font settings.
$sText[optional] The initial subtitle text - usually left empty, since it is set per page automatically on every navigation.

Return Value

SuccessThe header subtitle label's control ID.
FailureNull, with @error set to $INST_ERR_INVALID_GUI, if $hGUI is not a valid window handle.

Remarks

The control ID this returns is stored as $mWizard.mHeader.idSubheading, which is how each page's sSubheading ends up displayed on every navigation.

Related

_CreateHeader, _CreateHeaderTitle

Example

Local $idSub = _CreateHeaderSub($hGUI, $mCfg)
