Function Reference

_CreateHeaderTitle

Creates the header title label on a window.

_CreateHeaderTitle($hGUI, Const ByRef $mCfg, [$sText = ""])

Parameters

$hGUIThe wizard window handle to create the label on.
$mCfgThe installer config map, providing the window width and font name.
$sText[optional] The title text.

Return Value

SuccessThe header title label's control ID.
FailureNull, with @error set to $INST_ERR_INVALID_GUI, if $hGUI is not a valid window handle.

Remarks

Rendered in bold, 14pt, on a white background. Called by _CreateHeader() - there is normally no need to call this directly.

Related

_CreateHeader, _CreateHeaderSub

Example

Local $idTitle = _CreateHeaderTitle($hGUI, $mCfg, "Lumen Setup")
