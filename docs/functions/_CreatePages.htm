Function Reference

_CreatePages

Creates and returns an empty pages map to hold wizard pages.

_CreatePages()

Parameters

None.

Return Value

SuccessAn empty map, ready to be filled with pages via _AddPage().

Remarks

Called once by _NewWizard() to initialize $mWizard.mPages. There is normally no need to call this directly - use the _Add*Page() helpers, which call _AddPage() for you.

Related

_AddPage, _NewWizard

Example

Local $mPages = _CreatePages()
ConsoleWrite(UBound($mPages) & @CRLF)  ; 0
