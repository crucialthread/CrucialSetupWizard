Function Reference

_CreateSeparator

Creates a 1-pixel horizontal separator label on a window and sets its background color.

_CreateSeparator($hGUI, $iTop, $iWidth, $vBkColor)

Parameters

$hGUIThe wizard window handle to create the separator on.
$iTopThe Y position of the separator.
$iWidthThe width of the separator.
$vBkColorThe background color of the separator, as a color reference or an AutoIt color constant.

Return Value

SuccessThe separator control ID.
FailureNull, with @error set to $INST_ERR_INVALID_GUI, if $hGUI is not a valid window handle.

Remarks

Used both for the line under the header (by _CreateHeader()) and for the footer separator above the button row (by _NewWizard()).

Related

_CreateHeader, _NewWizard

Example

Local $idSep = _CreateSeparator($hGUI, 200, $mCfg.iWndWidth, 0xCCCCCC)
