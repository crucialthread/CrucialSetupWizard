_GetInstallerEvent

Returns the current installer event state.

_GetInstallerEvent()

Parameters

None.

Return Value

SuccessOne of the $EVENT_* constants: $EVENT_CLOSE_PAGE, $EVENT_DEFAULT, $EVENT_READY_TO_PROCEED, $EVENT_PROCESSING, or $EVENT_FINISH_PROCESS.

Remarks

Reads the module-level $g_iEventInstaller global. The event is set from a page's iStatus every time a page loads, and it is what the wizard uses to decide button captions, button enabled state, and whether the wizard should close.

Related

_SetInstallerEvent

Example

If _GetInstallerEvent() = $EVENT_PROCESSING Then
    ; buttons are disabled while a page is $eProcessingPage
    ConsoleWrite("Installer is busy" & @CRLF)
EndIf
