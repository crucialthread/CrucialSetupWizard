Function Reference

_GetPageCtrl

Returns the control ID registered under a named key in the page map.

_GetPageCtrl(ByRef $mPage, $sCtrlName)

Parameters

$mPageThe page map to look up the control on. Passed by reference.
$sCtrlNameThe control name previously passed to _SetPageCtrl() (normalization is applied automatically).

Return Value

SuccessThe control ID stored under $sCtrlName.
FailureNull, if the page is invalid or no control is registered under that name.

Remarks

Use this instead of storing raw control IDs in separate variables when a page's OnLoad/AfterLoad handler needs to reach back into its own controls (see _OnLoad_ReadyPage() for an example of the same pattern done via explicit handler args instead).

Related

_SetPageCtrl

Example

Local $idInput = _GetPageCtrl($mPage, "InputName")
If $idInput <> Null Then GUICtrlSetData($idInput, "default value")
