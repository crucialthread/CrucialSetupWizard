Function Reference

_GetWizardPage

Returns the page map at a given index from the wizard's pages collection.

_GetWizardPage(ByRef $mWizard, $iPage)

Parameters

$mWizardThe wizard map returned by _NewWizard(). Passed by reference.
$iPageThe 1-based page index to retrieve, as returned by an _Add*Page() helper.

Return Value

SuccessThe page map at $iPage.
FailureNull, if $mWizard has no mPages key or $iPage is not a valid index.

Remarks

Useful for inspecting or modifying a page after it has been added, using the index stored by an _Add*Page() helper (e.g. $mWizard.iReadyPageId).

Related

_AddReadyPage, _NewWizard

Example

Local $iReady = _AddReadyPage($mWizard, $mCfg, "Ready to install.")
Local $mReadyPage = _GetWizardPage($mWizard, $iReady)
ConsoleWrite($mReadyPage.sSubheading & @CRLF)
