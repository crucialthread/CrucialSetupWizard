Function Reference

_HandlerArgs

Creates a CallArgArray-style args array from up to 10 values, for use with _SetEventHandler().

_HandlerArgs([$v01 = Default [, $v02 = Default [, ... [, $v10 = Default]]]])

Parameters

$v01 .. $v10[optional] Up to 10 positional values to pass to a handler function. Trailing arguments left as Default are excluded from the result.

Return Value

SuccessAn array whose first element is the literal string "CallArgArray" followed by the arguments actually supplied, sized to @NumParams + 1.

Remarks

This builds the $aArgs array that _SetEventHandler() expects, and that in turn is passed on to _SetPageBtnOnClickEvent() or a page's OnLoad/AfterLoad/OnClose setter. Only pass as many values as the target handler actually needs - passing fewer keeps the array smaller.

Related

_SetEventHandler

Example

Local $aArgs = _HandlerArgs($idInputPath, "Install folder:", $hUpdateSrcFunc)
Local $mHandler = _SetEventHandler(_OnClick_SetFolder, $aArgs)
