Function Reference

_InitWizard

Entry point for starting the wizard - validates it is ready, then runs its event loop until the user finishes or cancels.

_InitWizard(ByRef $mWizard)

Parameters

$mWizardThe fully configured wizard map returned by _NewWizard(), with pages added via the _Add*Page() helpers. Passed by reference.

Return Value

-No meaningful return value. Shows an error MsgBox and returns immediately if the wizard is not ready (invalid, or has no pages). Otherwise runs until the user completes or cancels the wizard, then deletes the window.

Remarks

This is step 4 of the library's usage pattern, and the last call a script makes before handing control to the wizard. Internally it shows the window, loads the first page, and enters a message loop that handles Cancel/Close (with a confirmation prompt on non-processing pages), Back/Next navigation, and any custom button OnClick events registered via _SetPageBtnOnClickEvent().

Example

; Step 4 of the usage pattern - start the wizard and block until it closes
