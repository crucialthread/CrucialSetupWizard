_NewBtnCaptions

Creates a button captions config map with the label text for each wizard button and state.

_NewBtnCaptions([$sNext = $BTN_CAPTION_NEXT [, $sBack = $BTN_CAPTION_BACK [, $sCancel = $BTN_CAPTION_CANCEL [, $sFinish = $BTN_CAPTION_FINISH [, $sApply = $BTN_CAPTION_APPLY]]]]])

Parameters

$sNext[optional] Caption for the Next button. Default is "Next >".
$sBack[optional] Caption for the Back button. Default is "< Back".
$sCancel[optional] Caption for the Cancel button. Default is "Cancel".
$sFinish[optional] Caption the Next button switches to on the finish page. Default is "Finish".
$sApply[optional] Caption the Next button switches to on a ready/proceed page. Default is "Install".

Return Value

SuccessA map with keys sNext, sBack, sCancel, sFinish, sApply.

Remarks

Pass custom captions here to localize the wizard or to change "Install" to "Uninstall", "Update", etc. for a different kind of wizard. The values become the button captions the wizard uses once _NewWizard() runs.

Related

_NewBtnDim, _NewBtnCfg

Example

; Uninstaller-flavored captions
Local $mCapt = _NewBtnCaptions("Next >", "< Back", "Cancel", "Finish", "Uninstall")
Local $mBtnCfg = _NewBtnCfg(_NewBtnDim(), $mCapt)
