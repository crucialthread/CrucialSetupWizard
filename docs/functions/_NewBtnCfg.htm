Function Reference

_NewBtnCfg

Creates a button config map combining button dimensions and captions. Falls back to defaults for either part if an invalid map is passed.

_NewBtnCfg([$mBtnDim = _NewBtnDim() [, $mBtnCapt = _NewBtnCaptions()]])

Parameters

$mBtnDim[optional] A button dimension map from _NewBtnDim(). Replaced with _NewBtnDim() if not a map.
$mBtnCapt[optional] A button captions map from _NewBtnCaptions(). Replaced with _NewBtnCaptions() if not a map.

Return Value

SuccessA map with keys mDim (the dimension map) and mCapt (the captions map).

Remarks

This is the button half of the installer config, combined with window and font configs by _NewInstallerCfg().

Related

_NewBtnDim, _NewBtnCaptions, _NewInstallerCfg

Example

Local $mBtnCfg = _NewBtnCfg(_NewBtnDim(110, 30), _NewBtnCaptions("Next >", "< Back", "Cancel", "Finish", "Uninstall"))
