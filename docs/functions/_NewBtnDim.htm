_NewBtnDim

Creates a button dimension config map with width, height, horizontal gap and Y position for the Cancel/Back/Next button row.

_NewBtnDim([$iWidth = $BTN_W [, $iHeight = $BTN_H [, $iGap = $BTN_GAP [, $iYaxis = $BTN_Y]]]]])

Parameters

$iWidth[optional] Width of each button in pixels. Default is $BTN_W (130).
$iHeight[optional] Height of each button in pixels. Default is $BTN_H (34).
$iGap[optional] Horizontal gap between buttons in pixels. Default is $BTN_GAP (10).
$iYaxis[optional] Y position of the button row. Default is $BTN_Y.

Return Value

SuccessA map with keys iWidth, iHeight, iGap, iYaxis.

Remarks

Consumed by _NewBtnCfg() together with a captions map. _CreateButtons() uses these dimensions to center the three-button row horizontally in the window.

Related

_NewBtnCaptions, _NewBtnCfg, _CreateButtons

Example

; Slimmer, closer-spaced buttons
Local $mBtnDim = _NewBtnDim(110, 30, 6)
Local $mBtnCfg = _NewBtnCfg($mBtnDim)
