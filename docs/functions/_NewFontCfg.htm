Function Reference

_NewFontCfg

Creates a font config map with a font name and size, used for every label and button the wizard creates.

_NewFontCfg([$sName = $FONT_NAME [, $iSize = $FONT_SIZE]])

Parameters

$sName[optional] Font family name. Default is $FONT_NAME ("Segoe UI").
$iSize[optional] Font point size. Default is $FONT_SIZE (11).

Return Value

SuccessA map with keys sName (String) and iSize (Int).

Remarks

Passed to _NewInstallerCfg() to build the flat installer config. Every control created by the library's page templates and header/button helpers is styled with this font.

Related

_NewWndCfg, _NewInstallerCfg

Example

; Slightly larger font
Local $mFontCfg = _NewFontCfg("Segoe UI", 12)
Local $mCfg = _NewInstallerCfg(_NewWndCfg(), $mFontCfg)
