Function Reference

_NewInstallerCfg

Creates the single flat installer config map that is passed throughout the wizard - all layout, font and button settings are read from it. Falls back to defaults if invalid maps are provided.

_NewInstallerCfg([$mWndCfg = _NewWndCfg() [, $mFontCfg = _NewFontCfg [, $mBtnCfg = _NewBtnCfg()]]])

Parameters

$mWndCfg[optional] A window config map from _NewWndCfg(). Replaced with _NewWndCfg() if not a map.
$mFontCfg[optional] A font config map from _NewFontCfg(). Replaced with _NewFontCfg() if not a map.
$mBtnCfg[optional] A button config map from _NewBtnCfg(). Replaced with _NewBtnCfg() if not a map.

Return Value

SuccessA flat map with the keys every page-template and layout function in the library reads from: iWndWidth, iWndHeight, iFooterSepY, iHeaderHeight, iContentTop, iContentWidth, sFontName, iFontSize, iBtnWidth, iBtnHeight, iBtnGap, iBtnY, sBtnCaptNext, sBtnCaptBack, sBtnCaptCancel, sBtnCaptFinish, sBtnCaptApply. iBtnY is recalculated against $mWndCfg's window height unless it was explicitly overridden in $mBtnCfg.

Remarks

This is the config map every other public function in the library expects: _NewWizard(), every _Add*Page() helper, _CreateButtons() and the header constructors all take $mCfg built by this function. Flattening the three parts into one map means a page template needing a Y position, a font size and a button caption in the same call can read all three from a single argument instead of three.

Related

_NewWndCfg, _NewFontCfg, _NewBtnCfg, _NewWizard

Example

; Step 1 of the usage pattern - build the config with all defaults
Local $mCfg = _NewInstallerCfg()

; Or override just the window size
Local $mCfg2 = _NewInstallerCfg(_NewWndCfg(640, 400))
