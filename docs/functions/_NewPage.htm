Function Reference

_NewPage

Creates and returns a new page map with a subheading, status and an empty controls array.

_NewPage([$sSubheading = "" [, $iStatus = $eNormalPage]])

Parameters

$sSubheading[optional] Text shown in the header subtitle when this page is active.
$iStatus[optional] Page type - one of $eClosePage, $eNormalPage, $eProceedPage, $eProcessingPage, $eFinishPage. Default is $eNormalPage. An invalid value falls back to $eNormalPage.

Return Value

SuccessA map with keys sSubheading, iStatus, aControls (empty array) and mBtnEvents (empty map).

Remarks

Every one of the library's own page templates starts from a page built with _NewPage() and then adds controls and events to it. Build a page this way when adding a fully custom page to the wizard rather than one of the ready-made templates.

Related

_AddPage, _SetPageCtrl, _SetPageBtnOnClickEvent

Example

Local $mPage = _NewPage("Choose options", $eNormalPage)
; ... create controls on $mWizard.hWin, then:
_SetPageCtrl($mPage, $idCheckbox, "ChkOption")
_AddPage($mWizard.mPages, $mPage)
