Function Reference

_NewWizard

Creates and returns a new wizard map with a window, header, footer separator, buttons and an empty pages collection.

_NewWizard(Const ByRef $mCfg, $sTitle, $sHeaderTitle)

Parameters

$mCfgThe installer config map, from _NewInstallerCfg().
$sTitleThe window title and MsgBox title.
$sHeaderTitleThe text shown in the header title label.

Return Value

SuccessA map with keys hWin, sTitle, mHeader, idFooterSep, mButtons, mPages (empty), iPage (0).
FailureNull, with @error set to $INST_ERR_INVALID_CFG, and shows an error MsgBox, if $mCfg is not a valid installer config.

Remarks

This is step 2 of the library's usage pattern: build a config with _NewInstallerCfg(), then create the wizard with it. This applies the configured button captions, creates the window, header, footer separator and buttons, and sets up an empty pages collection ready for the _Add*Page() helpers.

Related

_NewInstallerCfg, _InitWizard

Example

; Steps 1-2 of the usage pattern
Local $mCfg = _NewInstallerCfg()
Local $mWizard = _NewWizard($mCfg, "Lumen Setup", "Lumen Setup Wizard")
