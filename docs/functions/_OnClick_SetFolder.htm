_OnClick_SetFolder

OnClick handler that opens a folder selection dialog and updates an input with the result.

_OnClick_SetFolder($idInputPath, $sPathLabel, $hUpdateSrcFunc)

Parameters

$idInputPathThe input control ID to update with the selected folder. The dialog opens pre-populated with its current value.
$sPathLabelLabel text used to build the folder selector dialog's title ("Select " & $sPathLabel).
$hUpdateSrcFunc[optional-by-caller] A function called with $idInputPath after the input is updated, or Default/invalid to skip.

Return Value

-No meaningful return value. Does nothing if the folder dialog is cancelled.

Remarks

_AddPathPage() wires this up on the path page's Browse button automatically. It isn't limited to the path page, though: you can register it the same way on a Browse button of your own, with _SetPageBtnOnClickEvent() and _HandlerArgs(), to reuse the same folder-picker behavior on a custom page:

Related

_AddPathPage, _SetPageBtnOnClickEvent, _HandlerArgs

Example

Func _OnPathChanged($idInputPath)
    $g_sInstallPath = GUICtrlRead($idInputPath)
EndFunc

Local $idBtnBrowse = GUICtrlCreateButton("Browse...", 300, 150, 80, 30)
_SetPageCtrl($mPage, $idBtnBrowse, "BtnBrowse")
_SetPageBtnOnClickEvent($mPage, $idBtnBrowse, _SetEventHandler(_OnClick_SetFolder, _
    _HandlerArgs($idInputPath, "Install folder:", _OnPathChanged)))
