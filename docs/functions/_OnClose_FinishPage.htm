_OnClose_FinishPage

OnClose handler that opens a file if a checkbox is checked.

_OnClose_FinishPage($idChkBoxOpenDoc, $sDocFile)

Parameters

$idChkBoxOpenDocThe checkbox control ID to check when the page closes.
$sDocFileThe path to the file to open (via ShellExecute()) if the checkbox is checked.

Return Value

-No meaningful return value; opens $sDocFile if the checkbox is checked.

Remarks

_AddFinishPage() registers this as the finish page's OnClose event automatically whenever it is given a $sDocFile - that's what wires up the "Open documentation" checkbox.

It isn't limited to the finish page, though: you can register it the same way on a custom page's OnClose event, pointing it at a checkbox and file of your own:

Related

_AddFinishPage, _SetEventHandler, _HandlerArgs

Example

$mPage.OnClose = _SetEventHandler(_OnClose_FinishPage, _
    _HandlerArgs($idChkBoxReadme, @ScriptDir & "\readme.txt"))
