Function Reference

_OnLoad_ReadyPage

OnLoad handler that calls a supplied function and shows its returned text in an info label.

_OnLoad_ReadyPage($idLblInfo, $hUpdateInfoFunc)

Parameters

$idLblInfoThe info label control ID to update, normally one registered on the page with _SetPageCtrl().
$hUpdateInfoFuncA function that takes no arguments and returns the String to display. Passing Default, or anything else that isn't a valid function, turns this into a no-op.

Return Value

-No meaningful return value; $idLblInfo is updated in place when $hUpdateInfoFunc is valid.

Remarks

The ready page uses this as its OnLoad event automatically whenever _AddReadyPage() is given a $hUpdateInfoFunc - that's the built-in way to show a dynamic summary (install path, selected components, disk space) that is only known once earlier pages have been visited.

It isn't limited to the ready page, though: you can register it the same way on a custom page's OnLoad event, with _SetEventHandler() and _HandlerArgs(), to get the same "recompute this label every time the page loads" behavior for a page of your own:

Related

_AddReadyPage, _SetEventHandler, _HandlerArgs

Example

Func _BuildDiskSpaceNote()
    Return "Free space at " & $g_sInstallPath & ": " & Round(DriveSpaceFree($g_sInstallPath), 1) & " GB"
EndFunc

; Wiring it up manually on a custom page, the same way _AddReadyPage() does internally
$mPage.OnLoad = _SetEventHandler(_OnLoad_ReadyPage, _HandlerArgs($idLblInfo, _BuildDiskSpaceNote))
