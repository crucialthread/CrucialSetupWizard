Function Reference

_ProgressStep

Updates the progress bar and status label for a single installer step, with a short delay before and after so the change is visible.

_ProgressStep($idLabel, $idProgress, $iStep, $iSteps, $sStatus)

Parameters

$idLabelThe status label control ID to update with $sStatus.
$idProgressThe progress bar control ID to update, as a percentage of $iStep / $iSteps.
$iStepThe current step number (0-based).
$iStepsThe total number of steps.
$sStatusThe status message to display next to the progress bar.

Return Value

-No meaningful return value; the label and progress bar controls are updated directly.

Remarks

Call this once per unit of work inside the function passed to _AddProgressPage(). The delay is 250 ms before/after each step, or 500 ms once the step reaches 100%, so the user can actually see the bar move rather than jumping straight to done.

Related

_AddProgressPage, _AfterLoad_ProgressPage

Example

Func _MyInstallProcess($idLblProgress, $idProgressbar)
    Local $aFiles = _MyFileList()
    For $i = 0 To UBound($aFiles) - 1
        ; ... copy $aFiles[$i] ...
        _ProgressStep($idLblProgress, $idProgressbar, $i + 1, UBound($aFiles), "Copying " & $aFiles[$i])
    Next
    Return True
EndFunc
