Function Reference

_SetEventHandler

Creates an event handler map holding a function reference and optional arguments.

_SetEventHandler($hHandler [, $aArgs = Default])

Parameters

$hHandlerA function reference to call when the event fires (e.g. _OnClick_SetFolder).
$aArgs[optional] An args array built with _HandlerArgs(). Default is Default (no arguments).

Return Value

SuccessA map with key hHandler and, if $aArgs was supplied, key aArgs. An empty map is returned if $hHandler is not a valid function.

Remarks

The map this returns is what _SetPageBtnOnClickEvent() and the page-template setters ($mPage.OnLoad, $mPage.AfterLoad, $mPage.OnClose) expect. It is read back and invoked automatically once the associated event fires.

Related

_HandlerArgs, _SetPageBtnOnClickEvent

Example

$mPage.AfterLoad = _SetEventHandler(_AfterLoad_FinishPage)
