_SetInstallerEvent

Sets the current installer event state.

_SetInstallerEvent([$iEvent = $EVENT_DEFAULT])

Parameters

$iEvent[optional] One of the $EVENT_* constants. Default is $EVENT_DEFAULT.

Return Value

-No meaningful return value; the function updates $g_iEventInstaller in place.

Remarks

Most callers never need this directly - the wizard sets it automatically from the page's iStatus on every navigation. A page template event handler such as _AfterLoad_FinishPage() calls it explicitly to request $EVENT_CLOSE_PAGE, which tells the wizard's event loop to exit on the next navigation.

Related

_GetInstallerEvent, _AfterLoad_FinishPage

Example

; Force the wizard to close on the next Next/Back/Cancel
_SetInstallerEvent($EVENT_CLOSE_PAGE)
