_SetPageBtnOnClickEvent

Registers an OnClick event handler for a specific button control on a page.

_SetPageBtnOnClickEvent(ByRef $mPage, $idBtnControl, $mEventHandler)

Parameters

$mPageThe page map to register the handler on. Passed by reference.
$idBtnControlThe control ID of the button to attach the event to (e.g. from GUICtrlCreateButton()).
$mEventHandlerAn event handler map created with _SetEventHandler().

Return Value

-Null if $mPage or $mEventHandler is invalid, or if $mEventHandler has no hHandler key. Otherwise no meaningful return value; $mPage.mBtnEvents is updated in place.

Remarks

Fired from the wizard's main event loop whenever a button other than Cancel/Back/Next posts a message while its page is current. This is how the Browse button on the path page template is wired up.

Related

_SetEventHandler, _OnClick_SetFolder

Example

Local $idBtnBrowse = GUICtrlCreateButton("Browse...", 300, 150, 80, 30)
Local $aArgs = _HandlerArgs($idInputPath, "Install folder:", Default)
_SetPageBtnOnClickEvent($mPage, $idBtnBrowse, _SetEventHandler(_OnClick_SetFolder, $aArgs))
