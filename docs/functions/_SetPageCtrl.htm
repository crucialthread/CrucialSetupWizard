Function Reference

_SetPageCtrl

Registers a control ID under a named key in the page map and stores it in the page's controls array.

_SetPageCtrl(ByRef $mPage, $idCtrl, $sCtrlName)

Parameters

$mPageThe page map to register the control on. Passed by reference.
$idCtrlThe AutoIt control ID returned by a GUICtrlCreate* function.
$sCtrlNameA descriptive name for the control, later normalized to i<Name>Id (e.g. "BtnNext" becomes "iBtnNextId") and used to retrieve it via _GetPageCtrl().

Return Value

SuccessThe control's index within $mPage.aControls.
FailureNull, with @error set to $INST_ERR_INVALID_CTRL, if $mPage is not a map, $idCtrl is not a valid control handle, or the internal array update fails.

Remarks

If the named control already exists on the page, its entry is updated in place; otherwise a new entry is appended to $mPage.aControls. All of the library's built-in page templates call this for every control they create, which is what lets the wizard show, hide, and manage a page's controls generically, without each page template having to track its own control list.

Related

_GetPageCtrl, _NewPage

Example

Local $idInput = GUICtrlCreateInput("", 10, 10, 200, 24)
_SetPageCtrl($mPage, $idInput, "InputName")
