Getting Started

Usage

If you installed Crucial Setup Wizard via the provided installer, all files are placed in an AutoIt's include directory and can be referenced from any project:

#include <CrucialSetupWizard.au3>

If you placed the files manually rather than using the installer, use the quoted form with a relative or absolute path:

#include "CrucialSetupWizard.au3"

Anatomy of a Wizard

Every wizard built with Crucial Setup Wizard follows the same four-step shape, regardless of how many or which pages it uses.

1. Create a config

Build the installer config map with _NewInstallerCfg(). Pass overrides for window, font or button settings, or take every default.

Local $mCfg = _NewInstallerCfg()

2. Create a wizard

Create the wizard window, header and buttons with _NewWizard(), giving it the config, a window title and a header title.

Local $mWizard = _NewWizard($mCfg, "Aurora Setup", "Aurora")

3. Add pages

Add one or more pages with the _Add*Page() template helpers, in the order they should appear.

_AddIntroPage($mWizard, $mCfg, "This wizard will install Aurora on your computer.")
_AddPathPage($mWizard, $mCfg, $g_sInstallPath, _OnInstallPathChanged)
_AddReadyPage($mWizard, $mCfg, "", "Ready to Install", _BuildInstallSummary)
_AddProgressPage($mWizard, $mCfg, _InstallAurora)

4. Start the wizard

Hand control to the wizard with _InitWizard(). This call blocks until the user finishes, cancels, or closes the window.

_InitWizard($mWizard)

Complete Worked Example

The following script installs Aurora, a small AutoIt library, so that it is available from any project via #include <Aurora.au3>. It detects the AutoIt install directory from the registry, tells a fresh install from an upgrade of one already present, lets the user pick where the library's help file and uninstaller go, shows a live summary of what it's about to do, copies files with a visible progress bar, and registers the include path so AutoIt can find the library afterward.

AuroraInstaller.au3

#include "CrucialSetupWizard.au3"

Global Const $REG_AUTOIT_KEY_WOW = "HKEY_LOCAL_MACHINE\SOFTWARE\WOW6432Node\AutoIt v3\AutoIt"
Global Const $REG_AUTOIT_KEY     = "HKEY_LOCAL_MACHINE\SOFTWARE\AutoIt v3\AutoIt"
Global Const $REG_AUTOIT_INCLUDE = "HKEY_CURRENT_USER\Software\AutoIt v3\AutoIt"
Global Const $REG_AURORA_KEY     = "HKEY_LOCAL_MACHINE\SOFTWARE\Aurora"

Global $g_sAutoItDir   = ""
Global $g_sIncludePath = ""
Global $g_sInstallPath = ""
Global $g_bIsUpgrade   = False

; Finds the AutoIt install directory and derives the include/install paths from it.
Func _DetectPaths()
    $g_sAutoItDir = RegRead($REG_AUTOIT_KEY_WOW, "InstallDir")
    If @error Then $g_sAutoItDir = RegRead($REG_AUTOIT_KEY, "InstallDir")
    If @error Then $g_sAutoItDir = "C:\Program Files (x86)\AutoIt3"

    $g_sIncludePath = $g_sAutoItDir & "\Include\Vendor"
    $g_sInstallPath = $g_sAutoItDir & "\Aurora"
EndFunc

; Looks for a prior install record and, if found, reuses its install folder and flags an upgrade.
Func _CheckExistingInstall()
    Local $sVersion = RegRead($REG_AURORA_KEY, "Version")
    $g_bIsUpgrade = Not @error And $sVersion <> ""

    If $g_bIsUpgrade Then
        Local $sExistingPath = RegRead($REG_AURORA_KEY, "InstallPath")
        If Not @error And FileExists($sExistingPath) Then $g_sInstallPath = $sExistingPath
    EndIf
EndFunc

Func _OnInstallPathChanged($idInputPath)
    $g_sInstallPath = GUICtrlRead($idInputPath)
EndFunc

Func _BuildInstallSummary()
    Local $sText = ""
    $sText &= " - Copy Aurora.au3 to: " & $g_sIncludePath & @CRLF
    $sText &= " - Copy Aurora.chm to: " & $g_sInstallPath & @CRLF
    $sText &= " - Register the include path with AutoIt"
    Return $sText
EndFunc

Func _InstallAurora($idLblProgress, $idProgressbar)
    Local $iStep = 0, $iSteps = 4

    _ProgressStep($idLblProgress, $idProgressbar, $iStep, $iSteps, "Creating folders...")
    DirCreate($g_sIncludePath)
    DirCreate($g_sInstallPath)
    $iStep += 1

    _ProgressStep($idLblProgress, $idProgressbar, $iStep, $iSteps, "Copying Aurora.au3...")
    If Not FileCopy(@ScriptDir & "\lib\Aurora.au3", $g_sIncludePath & "\Aurora.au3", 9) Then Return False
    $iStep += 1

    _ProgressStep($idLblProgress, $idProgressbar, $iStep, $iSteps, "Copying Aurora.chm...")
    If Not FileCopy(@ScriptDir & "\Aurora.chm", $g_sInstallPath & "\Aurora.chm", 9) Then Return False
    $iStep += 1

    _ProgressStep($idLblProgress, $idProgressbar, $iStep, $iSteps, "Registering include path...")
    Local $sExisting = RegRead($REG_AUTOIT_INCLUDE, "Include")
    If @error Then $sExisting = ""
    If Not StringInStr($sExisting, $g_sIncludePath) Then
        Local $sNew = ($sExisting = "") ? $g_sIncludePath : $sExisting & ";" & $g_sIncludePath
        RegWrite($REG_AUTOIT_INCLUDE, "Include", "REG_SZ", $sNew)
    EndIf
    RegWrite($REG_AURORA_KEY, "Version", "REG_SZ", "1.0.0")
    RegWrite($REG_AURORA_KEY, "InstallPath", "REG_SZ", $g_sInstallPath)

    Return True
EndFunc

Func _BuildAndRunInstaller()
    _DetectPaths()
    _CheckExistingInstall()

    Local $mCfg = _NewInstallerCfg()
    Local $mWizard = _NewWizard($mCfg, "Aurora Setup", "Aurora")

    Local $sIntroText = $g_bIsUpgrade _
        ? "This wizard will upgrade Aurora to the latest version." _
        : "This wizard will install Aurora, making it available from any project via:" & @CRLF & @CRLF & _
          " #include <Aurora.au3>"
    Local $sIntroSubHeading = ($g_bIsUpgrade ? "Upgrading " : "Welcome to ") & "Aurora Setup"
    _AddIntroPage($mWizard, $mCfg, $sIntroText, $sIntroSubHeading)

    _AddPathPage($mWizard, $mCfg, $g_sInstallPath, _OnInstallPathChanged, _
        "Install folder:", "Aurora.chm and the uninstaller will be copied to the folder below.")

    _AddReadyPage($mWizard, $mCfg, "", "Ready to Install", _BuildInstallSummary)

    Local $iProgress = _AddProgressPage($mWizard, $mCfg, _InstallAurora, "Aurora could not be installed.")
    Local $mProgressPage = _GetWizardPage($mWizard, $iProgress)
    Local $idLblProgress = _GetPageCtrl($mProgressPage, "LblProgress")
    Local $idProgressbar = _GetPageCtrl($mProgressPage, "Progressbar")

    _AddFinishPage($mWizard, $mCfg, $idLblProgress, $idProgressbar, _
        "Aurora has been installed successfully.", $g_sInstallPath & "\Aurora.chm")

    _InitWizard($mWizard)
EndFunc

_BuildAndRunInstaller()

What You'll See

Running the script opens the wizard and steps through five pages:

  1. Welcome. Intro text that reads differently depending on $g_bIsUpgrade - "install" the first time, "upgrade" if a prior version is found in the registry. Next is enabled; Back is disabled since this is the first page.
  2. Install folder. An editable path input, pre-filled with the detected (or previously recorded) install folder, plus a Browse button. Changing it updates $g_sInstallPath through _OnInstallPathChanged().
  3. Ready to Install. A summary label showing _BuildInstallSummary()'s current text - it re-reads $g_sIncludePath/$g_sInstallPath every time the page loads, so it always reflects what was chosen on the previous page. Next now reads "Install".
  4. Installing. A status label and a progress bar. Cancel, Back and Next are disabled the moment this page appears; _InstallAurora() runs automatically, advancing the bar through four steps, then the wizard moves on by itself - or stops and shows the failure message if any step fails.
  5. Finish. A completion message and an "Open documentation" checkbox, reusing the same label and progress bar controls from the Installing page. Next now reads "Finish"; checking the box opens Aurora.chm when the wizard closes.

Adding a Fully Custom Page

When none of the ready-made templates fit, build a page from scratch with _NewPage(), add controls with the normal GUICtrlCreate* functions, register them with _SetPageCtrl(), wire up any button clicks with _SetPageBtnOnClickEvent(), then add the page with _AddPage():

Local $mPage = _NewPage("Choose components", $eNormalPage)

GUISwitch($mWizard.hWin)
Local $idChkDocs = GUICtrlCreateCheckbox("Install help file", 15, $mCfg.iContentTop, 200, 24)
_SetPageCtrl($mPage, $idChkDocs, "ChkDocs")

_AddPage($mWizard.mPages, $mPage)

Handling Install Failure

The function passed to _AddProgressPage() must return a Boolean. Returning False shows the configured failure message and closes the wizard on the next navigation instead of advancing to the finish page - this is why _InstallAurora() in the worked example above checks the result of each FileCopy() call:

Func _InstallAurora($idLblProgress, $idProgressbar)
    If Not FileCopy(@ScriptDir & "\lib\Aurora.au3", $g_sIncludePath & "\Aurora.au3", 9) Then Return False
    Return True
EndFunc

Building a Matching Uninstaller

An uninstaller is usually its own small script, built the same way as the installer but with fewer pages - typically just Welcome, Ready, Progress and Finish, skipping the path page since the install location is already known (it can be read back from the same registry key the installer wrote it to). Overriding a single caption on the config map before creating the wizard is enough to turn the Ready page's "Install" button into "Uninstall":

Local $mCfg = _NewInstallerCfg()
$mCfg.sBtnCaptApply = "Uninstall"

Local $g_sInstallPath = RegRead($REG_AURORA_KEY, "InstallPath")

Local $mWizard = _NewWizard($mCfg, "Aurora Uninstall", "Aurora")
_AddIntroPage($mWizard, $mCfg, "This wizard will remove Aurora from your computer.")
_AddReadyPage($mWizard, $mCfg, "", "Ready to uninstall", _BuildUninstallSummary)
_AddProgressPage($mWizard, $mCfg, _UninstallAurora, "Uninstall failed.")

Tips

  • Reuse the config. Build $mCfg once per wizard and pass the same map to every _Add*Page() call - do not rebuild it per page.
  • Default means "no callback". Optional handler parameters such as $hUpdateSrcFunc and $hUpdateReadyPageFunc accept Default to skip the callback entirely.
  • Reuse progress/finish controls. Pass the progress page's label and progress bar control IDs straight into _AddFinishPage() - the finish page is designed to reuse them.
  • Override one caption instead of rebuilding the config. A config map is just a map - change a single field like $mCfg.sBtnCaptApply after _NewInstallerCfg() instead of calling _NewBtnCaptions() again.
  • Check @error after wizard calls. _NewWizard() and every _Add*Page() helper set @error on failure - check it, especially around _NewWizard(), before adding pages.
