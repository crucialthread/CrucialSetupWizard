Crucial Setup Wizard

Crucial Setup Wizard is an AutoIt library for building the setup wizard of an installer or uninstaller: the window, the header, the Cancel/Back/Next buttons, and a sequence of pages the user clicks through. Rather than laying out that window by hand for every project, a script describes its wizard as a short list of function calls and Crucial Setup Wizard takes care of the window plumbing, page switching, and button behavior underneath it.

Key Features

One config mapWindow size, fonts, button captions and layout metrics all live in a single map, built once and handed to every other call.
Five ready-made pagesWelcome, choose-a-folder, ready-to-proceed, progress and finish pages cover most installers without any custom GUI code.
A small event systemA page or button can run its own function on load, after load, on close, or on click, without changing how the wizard itself navigates.
Buttons that manage themselvesCancel, Back and Next enable, disable and relabel automatically from a page's status and its position in the wizard.
Plain maps everywhereA config, a page, and the wizard itself are all ordinary AutoIt maps, so they can be inspected, copied or adjusted with normal map syntax.

Quick Example

#include <CrucialSetupWizard.au3>

Local $mCfg    = _NewInstallerCfg()
Local $mWizard = _NewWizard($mCfg, "Lumen Setup", "Lumen")

_AddIntroPage($mWizard, $mCfg, "This wizard will install Lumen on your computer.")
_AddPathPage($mWizard, $mCfg, @ProgramFilesDir & "\Lumen", Default)
_AddReadyPage($mWizard, $mCfg, "Ready to install Lumen.")
_InitWizard($mWizard)
